05 / GAME LOGIC & p5.js DEV

Octopus Barista

An interactive, single-screen coffee counter simulation designed to model the physical and cognitive planning challenges associated with dyspraxia. This experience reframes coordination constraints into structured, manageable strategic decisions rather than unpredictable roadblocks.

  • ✦ Tangled Arms System: Rapidly jumping between operational stations or mismanaging orders accelerates a Tangle Meter (0-100). Higher metrics introduce execution lags and can freeze single limbs, forcing users to strategically pause or execute an active 'Untangle' action (R).
  • ✦ Action Queue Mechanics: User inputs buffer into a 3-step pipeline. Chaotic or reactive inputs prompt execution errors and 'Queue Slips' that invert intended ingredient paths (e.g., Ice → Espresso → Milk slips into Ice → Milk → Espresso), demanding cognitive rhythm over frantic button-mashing.
